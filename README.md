# Diabetes Prediction using Machine Learning

## Project Description
This project uses Machine Learning to predict whether a person is likely to have diabetes based on health-related parameters.

## Dataset
The project uses the Pima Indians Diabetes Dataset containing 768 records.

## Algorithm Used
- Logistic Regression

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Project Features
- Loads and processes the diabetes dataset
- Splits the data into training and testing sets
- Trains a Logistic Regression model
- Evaluates the model using accuracy and confusion matrix
- Takes patient details as input
- Provides a diabetes prediction

## Model Result
The model achieved an accuracy of approximately 71.43% on the test data.
